# YoursSquare.com workspace

This repository is a business workspace for managing advertising. It is not an application requiring a build or server.

## Start every task
- Use this existing checkout. Do not create Git worktrees unless explicitly requested.
- Read README.md, memory/business.md, memory/preferences.md, and memory/decisions.md before working.
- Read relevant campaign files before changing campaign plans.
- Distinguish confirmed business facts from proposals and unknowns. Never invent products, audiences, prices, budgets, results, or approvals.

## Keep useful memory
- Record user-confirmed durable facts in memory/business.md and working preferences in memory/preferences.md.
- Record consequential decisions with a date, context, and source in memory/decisions.md. Preserve historical decisions and mark superseded ones clearly.
- Keep campaign-specific plans, copy, asset references, and results in campaigns/.
- When instructions conflict, follow the latest explicit user instruction and update relevant memory. Ask about unresolved factual conflicts.
- Summarize memory changes at the end of a task. Do not store passwords, tokens, customer lists, or sensitive personal data.
- These files provide continuity only when saved in the repository and read by future tasks; do not claim automatic access to past chats or external platforms.

## Advertising work
- Planned tools: Canva, Instagram, Google Drive, and Facebook. Connections and account permissions have not been verified.
- Use available connected tools to inspect existing assets and campaigns when relevant. Never claim a platform is connected without checking.
- Prepare drafts and recommendations within the user's requested scope. Obtain explicit authorization before publishing content, sending messages, launching ads, changing budgets, or spending money.
- For each campaign capture the objective, offer, audience, channels, dates and timezone, budget and currency, asset links, copy, approval state, and measurement plan.
- Label estimated metrics and unapproved copy clearly. Do not present draft claims as verified business facts.
