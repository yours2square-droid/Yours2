# YoursSquare.com business workspace

Shared context for Codex to help plan and manage business advertising using Canva, Instagram, Google Drive, and Facebook.

## Where information lives
- `AGENTS.md`: instructions Codex reads when working in this repository.
- `memory/business.md`: confirmed business facts and missing context.
- `memory/preferences.md`: confirmed working preferences.
- `memory/decisions.md`: dated decisions and their sources.
- `campaigns/TEMPLATE.md`: copy this for each new campaign.

No software installation or running service is required. Start a task in this repository and ask Codex to read the business memory before working. Save changes in Git and push them to GitHub so future checkouts can use them. External accounts require separate connections and permissions; listing a service here does not connect it.

Suggested first task: “Read the business memory, help me complete the missing business details, and draft our first advertising campaign.”
